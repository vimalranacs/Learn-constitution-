# Constitution Atlas

Phased rebuild of the supplied Argon project. Start with `docs/IMPLEMENTATION_PLAN.md` for accurate delivery status and `docs/local-development.md` for PowerShell commands.

- `atlas-web/`: new modular React/TypeScript website, first Article 79/Parliament Atlas and lesson slice.
- `tools/`: read-only legacy audit and source-checked import.
- `data/legacy-quarantine.json`: preserved legacy content awaiting review; not deployed.
- `legacy/argon-original.zip`: original source/data checkpoint.
- `constitution_atlas_fullstack/`: untouched original extracted project.
- `docs/`: audit, architecture, decisions, source checks, testing and next steps.

The full research and learning application is **not complete**. A component or successful build alone does not satisfy a feature's acceptance gate.
