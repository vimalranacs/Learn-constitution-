# Design system — first slice

Light editorial surfaces; ink #202B30, muted #58686D, background #F8F8F5, accent #285F62, border #DCE3DF. System sans-serif UI and Georgia headings avoid third-party font requests. Base body 17px, reading line-height 1.85, lesson width 780px including padding.

Shared components: Shell, Composition, Source, KnowledgeCheck. Atlas uses a dominant relationship view beside source inspection; Learn uses one reading column and an isolated reasoning activity. All links and inputs have visible focus. The graph has an accessible textual equivalent; narrow mobile uses text rather than unreadably tiny diagram labels. No animation or dependence on motion.

This is not the final component library. Dark theme, search, expandable graph inspector, tutor and personal workspace remain planned. Browser validation must precede marking responsive QA complete.
